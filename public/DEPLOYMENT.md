# دليل نشر موقع "حارس ونقاء" على استضافة Hostinger (معالج التثبيت الذكي)

تم تزويد هذا المشروع بـ **معالج تثبيت ويب متكامل (`install.php`)** يُنجز جميع خطوات تهيئة قاعدة البيانات، استيراد الجداول، ضبط كلمة مرور المشرف، وتوليد ملف التكوين الأمني `api/.env` تلقائياً بضغطة زر واحدة، دون الحاجة للتعامل اليدوي مع phpMyAdmin أو تحرير ملفات PHP.

---

## متطلبات التشغيل على Hostinger
- **نوع الاستضافة:** استضافة Hostinger المشتركة (Shared Hosting) أو Cloud Hosting.
- **إصدار PHP:** ينصح باختيار **PHP 8.1 أو 8.2 أو 8.3**.
- **امتدادات PHP المطلوبة:** `pdo` و `pdo_mysql` (مفعلة افتراضياً في Hostinger).
- **قاعدة بيانات MySQL:** قاعدة بيانات فارغة ومستخدم مع كامل الصلاحيات (All Privileges).

---

## خطوات النشر السريع (3 خطوات فقط)

### الخطوة 1: إنشاء قاعدة بيانات فارغة في Hostinger hPanel
1. سجل الدخول إلى لوحة تحكم **Hostinger hPanel**.
2. توجه إلى **Databases** -> **Management** (إدارة قواعد البيانات).
3. اضغط على **Create New MySQL Database And Database User**:
   - **Database Name:** اسم قاعدة البيانات (مثال: `u123456789_hares`).
   - **Username:** اسم المستخدم لقاعدة البيانات (مثال: `u123456789_admin`).
   - **Password:** كلمة مرور قوية لقاعدة البيانات (احفظها لاستخدامها في المعالج).
4. اضغط **Create**.

---

### الخطوة 2: بناء المشروع ورفع محتويات مجلد `dist/`
1. على جهازك، قم بتشغيل أمر البناء:
   ```bash
   npm run build
   ```
   *سيقوم Vite تلقائياً بتجميع الواجهة ونقل مجلد `api/` وملف `install.php` وملف `database.sql` وملف `.htaccess` داخل مجلد `dist/`.*

2. افتح **File Manager** في Hostinger hPanel وادخل إلى مجلد:
   ```
   public_html/
   ```
3. ارفع **محتويات مجلد `dist/` بالكامل** إلى `public_html/`:
   - `index.html`
   - `install.php` (معالج التثبيت)
   - `database.sql` (مخطط الجداول والبيانات الأولية)
   - `.htaccess` (توجيه React وحماية الملفات الأمنية)
   - مجلد `api/` (واجهات البرمجة الخلفية)
   - مجلد `assets/` (الملفات المجمعة والخطوط)

> **تأكيد صلاحيات المجلدات:** تأكد أن مجلد `public_html/api` يحمل تصريح `755` أو قابل للكتابة ليتمكن المعالج من إنشاء ملف `api/.env` وقفل التثبيت.

---

### الخطوة 3: تشغيل معالج التثبيت وحذف الملف بعد النجاح
1. افتح المتصفح وتوجه إلى الرابط:
   ```
   https://your-domain.com/install.php
   ```
2. سيقوم المعالج تلقائياً بفحص المتطلبات والتأكد من دعم الخادم.
3. أدخل بيانات الاتصال بقاعدة البيانات التي أنشأتها في الخطوة 1:
   - **خادم قاعدة البيانات (DB Host):** اتركه `localhost` (الافتراضي في Hostinger).
   - **اسم قاعدة البيانات:** (مثال: `u123456789_hares`).
   - **اسم مستخدم قاعدة البيانات:** (مثال: `u123456789_admin`).
   - **كلمة مرور قاعدة البيانات.**
4. حدد اسم مستخدم المشرف (افتراضي: `admin`) وكلمة المرور الجديدة الخاصة بك (8 خانات على الأقل تتضمن أرقاماً وحروفاً).
5. (اختياري) أدخل مفتاح Google Gemini API إذا كنت ترغب في تشغيل ميزات الذكاء الاصطناعي.
6. اضغط على **"بدء التثبيت وتهيئة النظام"**.
7. سيقوم المعالج خلال ثوانٍ بـ:
   - اختبار الاتصال بقاعدة البيانات.
   - استيراد 15 جدولاً مع كافة البيانات الأولية والترجمات.
   - تشفير كلمة مرور المشرف وتعيينها في قاعدة البيانات.
   - توليد `api/.env` ومفتاح تشفير `TOKEN_SECRET` العشوائي.
   - قفل المعالج تلقائياً بإنشاء `api/install.lock`.

8. **إجراء أمني إلزامي:** بعد ظهور شاشة النجاح، افتح **File Manager** واحذف ملف `install.php` فوراً لضمان حماية موقعك بنسبة 100%.

## استكشاف الأخطاء وحلولها الشائعة (Hostinger Troubleshooting)

### 1. فشل الاتصال بقاعدة البيانات (Access denied أو Unknown database)
- **سبب شائع 1:** في Hostinger، يُضاف دائماً رقم حسابك كبادئة لاسم القاعدة والمستخدم (مثل `u123456789_`). تأكد من كتابة الاسم كاملاً بالبادئة كما يظهر في hPanel.
- **سبب شائع 2:** تأكد من إسناد المستخدم لقاعدة البيانات ومنحه جميع الصلاحيات (All Privileges).
- **سبب شائع 3:** تأكد من عدم وجود مسافات إضافية قبل أو بعد كلمة المرور.

### 2. رسالة "المعالج مقفل لأسباب أمنية"
- تعني وجود ملف `api/install.lock`. لإعادة تشغيل المعالج، احذف الملف `api/install.lock` عبر مدير الملفات.

### 3. رسالة "تعذر كتابة ملف api/.env"
- تأكد من أن تصريح مجلد `public_html/api/` هو `755` أو `775` حتى يتمكن خادم الويب (Apache/PHP) من إنشاء ملف الإعدادات المشفر.

## بيانات تسجيل الدخول للوحة التحكم
- **الرابط:** `https://your-domain.com/admin`
- **اسم المستخدم:** الاسم الذي قمت بتحديده في المعالج (أو `admin`).
- **كلمة المرور:** كلمة المرور التي عينتها أثناء التثبيت في المعالج.

الموقع الآن مهيأ ومحمي بالكامل ويعمل بأعلى درجات الأمان والكفاءة.
